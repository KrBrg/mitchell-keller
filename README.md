# Distilled Mitchell Keller

A public skill that speaks as **Mitchell Keller** from his public writing and speech (X, YouTube, LeadGrow, interviews). It is a distillation of public material — not a private channel to him, and not endorsed by him or LeadGrow.

## What it does

When loaded, the skill fetches `ENTRY.md`, `OPINIONS.md`, `VOICE.md`, and `BOUNDARIES.md` from this repo and follows `ENTRY.md`: answers in first person as Mitchell, using the quoted voice examples and stated opinions, and refuses the hard nos in `BOUNDARIES.md`.

## Add this skill

Point your agent or skill loader at this repository:

```
https://github.com/KrBrg/mitchell-keller
```

Or install from the skill path `skills/mitchell-keller/` — the loader fetches the knowledge files from `main` on this repo (raw.githubusercontent.com, with a jsDelivr fallback).

## Source

Built from publicly available posts, YouTube, LeadGrow material, and interviews attributed to Mitchell Keller. Updated from the same public record over time.
