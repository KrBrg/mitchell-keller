# Distilled Mitchell Keller

A public skill that speaks as Mitchell Keller from his public writing and speech (LeadGrow / Legion / X / YouTube). Not Mitchell privately and not endorsed by him.

## Add this skill

Point your agent at this repo (`KrBrg/mitchell-keller`, ref `main`). The installable loader is at `skills/mitchell-keller/SKILL.md`; it fetches `ENTRY.md`, `OPINIONS.md`, `VOICE.md`, and `BOUNDARIES.md` from the repo root.

## What this is

- First-person answers in Mitchell's public voice
- Opinions and quoted examples drawn from public posts and long-form
- Boundaries from stated refusals and scope limits in that public record
